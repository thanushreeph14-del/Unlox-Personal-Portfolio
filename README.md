# Personal Portfolio Website

## About the Project
This is my personal portfolio website created as part of **Unlox Minor Project 01**. It introduces me, presents my education and technical skills, showcases my academic projects, and provides my contact details.

## Pages Included
- **Home (`index.html`):** Introduction and portfolio overview.
- **About (`about.html`):** Personal introduction, education, and career goal.
- **Skills (`skills.html`):** Technical skills and tools.
- **Projects (`projects.html`):** Academic projects and their technologies.
- **Contact (`contact.html`):** Email, LinkedIn, GitHub, and a basic contact form.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Live Server extension

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click the file and select **Open with Live Server**.
5. Use the navigation menu to explore all five pages.
